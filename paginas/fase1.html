HTML: Estrutura e Conteúdo da Página

HTML (HyperText Markup Language) é a linguagem padrão usada para criar páginas da web. Ele estrutura o conteúdo da página usando tags que indicam diferentes elementos, como títulos, parágrafos, imagens, links, etc.

Estrutura básica de um documento HTML

  • < !DOCTYPE html >: Declara que o documento é HTML5.
  • < html >: Elemento raiz da página.
  • < head >: Contém informações da página, como título, metadados, links para CSS e scripts.
  • < title >: Título que aparece na aba do navegador.
  • < body >: Conteúdo visível da página.

Algumas outras tags bastante conhecidas:

  • < h1 > e < h6>: Cabeçalhos, do mais importante (h1) ao menos importante (h6).
  • < p >: Parágrafo.
  • < a href="URL" >: Link.
  • < img src="imagem.jpg" alt="descrição" >: Imagem.
  • < ul > e < ol >: Listas (não ordenada e ordenada).
  • < li >: Item de lista.
  • < div >: Container genérico para agrupar elementos.

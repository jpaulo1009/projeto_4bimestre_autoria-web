CSS: Estilo e Design da Página

CSS, que significa Cascading Style Sheets (Folhas de Estilo em Cascata), é uma linguagem usada para descrever a apresentação visual de documentos escritos em HTML ou XML. Enquanto o HTML estrutura o conteúdo de uma página web, o CSS é responsável por definir como esse conteúdo será exibido — como cores, fontes, espaçamentos, layouts e muito mais.

Formas de aplicar CSS ao HTML

O CSS pode ser aplicado de três maneiras principais, e o navegador as lê em ordem de prioridade (da maior para a menor): local (inline), incorporado (interno, embedded) e externo (linked)

  1. CSS Local (inline)

    2. É aplicado diretamente dentro da tag HTML, usando o atributo style.

  2. CSS Incorporado (interno, embedded)

    3. É inserido dentro da tag < style > no cabeçalho < head > do documento HTML.

  3. CSS Externo (linked)

    4. Método mais profissional e usado. É colocado em um arquivo separado (.css), e o HTML o importa com a tag < link > no < head >.

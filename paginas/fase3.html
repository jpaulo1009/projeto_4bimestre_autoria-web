JavaScript: Interatividade na Página

O JavaScript (JS) é uma linguagem de programação usada para dar vida e interatividade às páginas da web. Enquanto o:

  • HTML define o conteúdo,
  • CSS define o estilo,
  • JavaScript define o comportamento dinâmico.

Formas de adicionar JavaScript

  1. Inline (na tag HTML)

    2. Dentro da tag HTML, usando atributos como onclick, onmouseover, etc.

  2. Interno (dentro do < script > no HTML)

  3. Externo (em um arquivo separado)
